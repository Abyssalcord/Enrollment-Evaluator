# About the Project
A streamlined automated enrollment and application evaluation system designed to process freshman, transferee, and continuing student records, calculate academic metrics, and generate dynamic evaluation reports.
#
# Key Features:
- Applicant Classification: Automatically categorizes applicants into freshman, transferee, or continuing student workflows.
- Academic Verification: Validates applicant GPA thresholds and entrance exam scores against institutional standards.
- Specialized Track Screening: Checks academic backgrounds, such as verifying if an applicant completed the STEM strand.
- Automatic Period Load Assignment: Calculates and assigns the appropriate unit load for the upcoming term based on evaluation results.
- Dynamic Results Page: Prints out a comprehensive evaluation summary page detailing applicant status, approved load, and next steps.
